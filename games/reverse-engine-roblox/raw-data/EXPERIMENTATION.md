## 🔬 FORMULA D: REACTION

**Core:** Stimulus appears → React correctly or die

**Not turn-based.** Real-time reaction.

```
STRUCTURE:
- Something happens (visual/audio cue)
- Players must REACT (press button, move, etc.)
- Too slow = eliminated
- Wrong reaction = eliminated
- Fastest/correct = survives
```

**Why it creates tension:**
- Split-second decisions
- "Did I press it in time?!"
- Near-misses are DRAMATIC
- Simple to understand

### Concept D1: QUICK DRAW

```
Everyone in a standoff
Random "DRAW!" signal
First to tap = shoots
Slowest = eliminated
Shoot too early (before signal) = eliminated

Western showdown vibes.
Understand in 10 seconds.
Pure reaction.
```

### Concept D2: FLOOR FLASH

```
Standing on a grid
Random tiles FLASH red (warning!)
You have 1 second to MOVE off
Standing on red when it activates = eliminated

Continuous real-time.
Reaction + movement.
Like Dance Dance Revolution meets elimination.
```

### Concept D3: COLOR SHOUT

```
Colors flash on screen rapidly
When YOUR color appears, TAP
Miss your color = lose a life
Tap wrong color = lose a life
Last one with lives = wins

Simple, frantic, reaction-based.
```

## 🔬 FORMULA E: TIMING

**Core:** There's a perfect moment → Act at that moment

**Different from Reaction:** You CHOOSE when to act, not respond to stimulus.

```
STRUCTURE:
- Opportunity window exists
- Acting too early = bad
- Acting too late = bad
- Perfect timing = reward
- It's about PATIENCE + PRECISION
```

**Why it creates tension:**
- "Is NOW the right moment?"
- Watching others act (or not)
- The longer you wait, the more tense

### Concept E1: JUMP GAP

```
Platforms moving
Gap between them changes
Jump at PERFECT moment = land safely
Jump too early/late = fall

Like Flappy Bird timing but multiplayer.
Last one standing wins.
```

### Concept E2: HOT SEAT

```
A "death timer" randomly selects players
When selected, you have X seconds
Press button to PASS it to someone else
But: Passing has a COOLDOWN
If timer hits 0 on you = eliminated
Timing when to pass is crucial

Hot potato but with timing strategy.
```

### Concept E3: SHRINKING WINDOW

```
Safe zone appears
It SHRINKS over time
Enter the safe zone before it closes
But: Entering EARLY makes you a target
Entering LATE risks missing it
Timing your entry = survival

Risk/reward timing.
```

## 🔬 FORMULA F: CHAOS RACE

**Core:** Real-time race with unpredictable obstacles/chaos

**Not turn-based.** Continuous movement and chaos.

```
STRUCTURE:
- Race to a goal
- Obstacles appear randomly
- Other players can interfere
- Physics chaos = unpredictable
- First to finish (or last standing) wins
```

**Why it creates tension:**
- "Almost there... NO!"
- Comebacks possible
- Chaos = anyone can win
- Shareable wipeout moments

### Concept F1: OBSTACLE DASH

```
Race through obstacle course
Obstacles appear in real-time
Falling = respawn (time penalty) or elimination
First to finish wins

Fall Guys style but simpler.
```

### Concept F2: PUSH RACE

```
Race on narrow track
Can PUSH other players
Push them off = they're slowed/reset
But pushing slows YOU too
Balance racing vs sabotage

Real-time Knockout! vibes.
```

### Concept F3: ESCALATOR ESCAPE

```
Floor is an ESCALATOR going backward
You run FORWARD against it
Obstacles come at you
Stop running = you fall off the back
Race to reach the top

Endless runner meets battle royale.
```

## 🔬 FORMULA G: BLUFF

**Core:** Make claims (true or false) → Others decide to believe or call out

**Social deduction but SIMPLIFIED.**

```
STRUCTURE:
- Player makes a CLAIM
- Others vote: BELIEVE or CALL BLUFF
- If bluff called correctly: Bluffer eliminated
- If wrong call: Caller eliminated
- If bluff not called: Bluffer scores/survives
```

**Why it creates tension:**
- "Are they lying?"
- Reading faces/patterns
- Social dynamics
- Poker-style mindgames

### Concept G1: CLAIM GAME

```
Each round: One player makes a CLAIM
"I have the highest number" (cards dealt secretly)
Others vote: TRUE or FALSE
If majority correct = Claimer eliminated (if lying)
If majority wrong = Claimer survives

Simple bluffing, no complex rules.
```

### Concept G2: FAKER

```
Task appears: "Jump 3 times"
Everyone does it... but ONE person is the FAKER
Faker doesn't know the real task, must GUESS
Others vote: Who's the faker?
If faker identified = faker out
If wrong person accused = accuser out

Simplified Among Us.
```

### Concept G3: BOLD CLAIM

```
Everyone secretly gets a NUMBER (1-10)
Go around, each claims: "My number is higher than X"
Can lie or tell truth
Next player can: ACCEPT (your turn) or CHALLENGE
Challenge = both reveal, loser eliminated

Liar's dice simplified.
```

## 🔬 FORMULA H: RISK BET

**Core:** Bet/Risk resources → Big bet can win big or lose big

**Gambling tension without real money.**

```
STRUCTURE:
- You have POINTS/LIVES/RESOURCES
- Each round: Choose how much to risk
- Outcome determined (luck/skill/others)
- Win = multiply your bet
- Lose = lose your bet
- Lowest score eliminated each round
```

**Why it creates tension:**
- "Do I go all in?"
- Watching others' bets
- Comeback potential
- Dramatic swings

### Concept H1: ALL IN

```
Everyone has chips
Each round: Bet on LEFT or RIGHT
Hidden choice
Reveal: Random side wins
Winners double, losers lose bet
Lowest chips = eliminated

Simple betting + elimination.
```

### Concept H2: PUSH YOUR LUCK

```
Points available in center
Take turns grabbing points
BUT: Each grab = chance of "BUST"
If you bust = lose ALL grabbed points this round
Can BANK anytime (keep points, end turn)
Lowest total after X rounds = eliminated

Press Your Luck style.
```

### Concept H3: MULTIPLIER MAYHEM

```
Each round: Choose a MULTIPLIER (1x, 2x, 3x, 5x, 10x)
Then: Random event
If you SURVIVE the event = points × multiplier
If you FAIL = points ÷ multiplier (or lose all)
Higher multiplier = higher risk

Risk/reward with elimination.
```

## 🔬 FORMULA I: MEMORY

**Core:** Remember information → Recall correctly → Survive

```
STRUCTURE:
- Information shown (pattern, sequence, positions)
- Information hidden
- Players must RECALL
- Wrong recall = eliminated
- Correct = survives
- Gets HARDER each round
```

**Why it creates tension:**
- "Wait, was it blue then red or..."
- Progressive difficulty
- Skill-based but simple
- Anyone can focus and win

### Concept I1: SEQUENCE SURVIVOR

```
A sequence shown: 🔴🔵🟢🔴
Then hidden
Everyone must TAP the sequence
Wrong sequence = eliminated
Sequence gets LONGER each round

Simon Says battle royale.
```

### Concept I2: SPOT THE CHANGE

```
Scene shown for 5 seconds
Scene changes slightly
Find the change
Slowest to find = eliminated

Memory + observation.
```

### Concept I3: WHO WAS WHERE

```
Players shown in positions
Screen goes BLACK for 3 seconds
Players MOVE in the dark
Lights on: "Who moved?"
Vote on who moved
Wrong vote = eliminated

Memory + social.
```

## 🔬 FORMULA J: RHYTHM

**Core:** Beat/Pattern → Match it → Survive

```
STRUCTURE:
- A rhythm/beat plays
- Players must MATCH it (tap, move, action)
- Off-beat = lose points/life
- Stay on beat = survive
- Song gets FASTER/HARDER
- Last one keeping rhythm wins
```

**Why it creates tension:**
- Music creates natural drama
- Watching others struggle/succeed
- Gets progressively harder
- Satisfying to nail

### Concept J1: BEAT BATTLE

```
Music plays
Everyone must TAP on beat
Miss beats = lose hearts
Lose all hearts = eliminated
Music gets faster

Rhythm game + elimination.
```

### Concept J2: DANCE OR DIE

```
Dance moves shown on beat
Everyone must COPY the move on beat
Wrong move = damage
Off-beat = damage
Last dancer standing wins

Dancing battle royale.
```

### Concept J3: RHYTHM RACE

```
Race track
You can only MOVE on the beat
Off-beat movement = frozen
On-beat = you move forward
First to finish wins

Racing + rhythm combined.
```
