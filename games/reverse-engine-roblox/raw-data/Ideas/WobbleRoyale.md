# Wobble Royale 🫨👑

**Status:** SAVED - Viral clip potential
**Theme:** Drunk physics battle
**Style:** Ragdoll chaos + Battle royale

---

## 🎮 Core Concept

Everyone has WOBBLY, drunk-like controls (like QWOP or Gang Beasts). Hard to walk straight. Ragdoll physics. Push/punch others off platform. Fall off = eliminated. Accidental self-eliminations are common.

**The Twist:** Fighting your OWN controls is half the battle. Chaos is guaranteed.

## 🫨 Wobble Physics

### Movement Characteristics
```
STANDING:
- Constant subtle sway
- Random micro-stumbles
- Must actively balance
- Can fall over standing still

WALKING:
- Exaggerated leg movements
- Unpredictable direction drift
- Speed varies uncontrollably
- Trips over nothing

RUNNING:
- Very fast but VERY unstable
- High chance of face-plant
- Hard to stop
- Momentum carries you

TURNING:
- Delayed response
- Over-rotation common
- Spin out possible
```

### Balance Meter
```
BALANCE: ████████░░ 80%

DRAINS FROM:
- Running (-20%)
- Getting punched (-30%)
- Hitting obstacles (-15%)
- Near edge (-10% passive)

RECOVERS FROM:
- Standing still (+5%/sec)
- Crouching (+10%/sec)
- Grabbing ledge (+3%/sec)

AT 0% BALANCE:
- Fall down ragdoll
- Vulnerable for 2-3 sec
- Can be pushed off easily
```

## 👊 Combat Mechanics

### Punch
| Property | Value |
|----------|-------|
| Damage | None (knockback only) |
| Knockback | Medium |
| Range | Short |
| Accuracy | LOW (hard to aim) |
| Self-Effect | -10% balance |

### Grab & Throw
| Property | Value |
|----------|-------|
| Grab Range | Very short |
| Throw Distance | Medium |
| Aim | Even worse than punch |
| Self-Effect | -25% balance |
| Counter | Can grab back |

### Headbutt
| Property | Value |
|----------|-------|
| Knockback | HUGE |
| Range | Lunge forward |
| Accuracy | Terrible |
| Self-Effect | -40% balance, dizzy |
| Risk | Often misses, fall off |

### Combat Flow
```
ATTEMPT PUNCH:
→ Wind up (telegraph)
→ Swing (might miss)
→ Hit? Knockback!
→ Miss? Stumble forward
→ Either way, lose balance

GRAB ATTEMPT:
→ Reach out (slow)
→ Grab? Hold enemy
→ Throw direction is iffy
→ Miss? Hug air, stumble

HEADBUTT:
→ Lower head
→ CHARGE
→ Hit? Massive knockback!
→ Miss? Launch yourself off platform
```

## 📊 Skill vs Luck Balance

### What Matters
```
LUCK (50%):
- Physics randomness
- Stumble timing
- Who happens to be near edge

SKILL (30%):
- Balance management
- Positioning awareness
- Attack timing

CHAOS (20%):
- Pure unpredictable madness
- Embrace it
```

### Why This Balance Works
- Anyone can win (accessible)
- Skilled players slightly favored
- Chaos keeps it funny
- Never feel "outplayed" unfairly
