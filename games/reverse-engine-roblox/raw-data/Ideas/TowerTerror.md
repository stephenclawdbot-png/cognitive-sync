# 🗼 TOWER TERROR (Stack & Collapse)

> **Formula:** L (Stack & Collapse)
> **Core Mechanic:** Add blocks to tower, collapse on your turn = eliminated
> **Theme:** Cute animals playing giant Jenga
> **Status:** ORIGINAL CONCEPT - Physics tension

---

## 🎯 Core Concept

```
┌─────────────────────────────────────────────────────────────────┐
│                       TOWER TERROR                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   A TOWER exists in the center (shared by all)                  │
│   Players take TURNS                                            │
│                                                                 │
│   YOUR TURN:                                                    │
│   - You MUST add a block to the tower                           │
│   - Choose WHERE to place it                                    │
│   - Physics determines if it holds                              │
│                                                                 │
│   IF TOWER FALLS ON YOUR TURN:                                  │
│   - YOU are eliminated                                          │
│   - Tower rebuilds (smaller)                                    │
│   - Game continues                                              │
│                                                                 │
│   LAST PLAYER STANDING = WINS                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

## 🎮 Game Flow

```
SETUP:
- 8 players
- Tower starts with base (stable)
- Turn order randomized

EACH TURN (10 sec limit):
- Current player gets a BLOCK
- Must place it on the tower
- Can rotate, position carefully
- Release block
- Physics resolves
- If stable: Next player's turn
- If collapse: Current player eliminated

PROGRESSION:
- Tower gets TALLER and more unstable
- Blocks might vary (shapes, sizes)
- Wind might blow? (chaos element)
- Pressure increases each round

END:
- Last player remaining = WINNER
- Or: Final 2 players, tower hasn't fallen = both win?
```
