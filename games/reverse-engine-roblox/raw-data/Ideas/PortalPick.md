# 🚪 PORTAL PICK

> **Formula:** A (Timer-Reveal)
> **Core Mechanic:** Pick a portal, one is safe, others are traps
> **Theme:** Cute animals choosing mystery doors
> **Status:** ORIGINAL CONCEPT - Luck + Gut Instinct

---

## 🎯 Why This Is ORIGINAL

Classic game show mechanic turned battle royale:
- Door #1, #2, or #3?
- One is safe, others eliminate
- Pure luck meets gut feeling

**The core tension:** Which portal leads to safety?

## 🧠 The Mind Games

### Pure Gut:
```
"I have NO information..."
"It's literally random..."
"But my GUT says blue..."
"Or is that just because I like blue?"
"AHHH JUST PICK ONE!"
```

### False Patterns:
```
"Red was safe last round..."
"So it won't be red again... right?"
"Or maybe the game WANTS me to think that?"
"IS THERE EVEN A PATTERN?!"
(There isn't. It's random. But humans see patterns everywhere.)
```

### Crowd Psychology:
```
"Everyone is going to red..."
"Should I follow the crowd?"
"But crowd doesn't affect which is safe!"
"Still... safety in numbers feels right..."
"NO! The portal is random! Crowd doesn't matter!"
"...but what if it does somehow..."
```

### Superstition:
```
"Green has been safe 3 times..."
"It's a lucky portal!"
"I'm going green!"
(It's not lucky. It's random. But humans believe anyway.)
```

## 🔢 The Math

```
3 PORTALS:
- 33.3% chance each portal is safe
- 66.6% chance you pick a trap

EXPECTED SURVIVAL:
- Round 1: 33% survive (on average)
- But variance is HIGH
- Could be 90% pick safe, could be 10%

PROBABILITY DOESN'T CARE ABOUT CROWD:
- If 8 people pick red, 1 picks blue, 1 picks green
- If blue is safe: 8 die, 2 live
- If red is safe: 8 live, 2 die
- The PORTAL is random, not affected by choices
```
