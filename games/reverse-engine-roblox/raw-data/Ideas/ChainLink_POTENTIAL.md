## 🎯 Why This Is ORIGINAL

No game does this:
- Not voting (that's elimination)
- Not teams (that's fixed groups)
- This is DYNAMIC SOCIAL CHAINS

**The core tension:** Who's linking to me? Who should I link to?

## 🧠 The Mind Games (Why This Is GENIUS)

### Popularity Contest:
```
"Who looks like they'll get the most links?"
"If I link to the popular player..."
"But if EVERYONE links to them, it's just a hub, not a chain!"
"Chains need A→B→C, not A→B, C→B, D→B"
```

### Chain Building:
```
"If I link to B, and B links to C, and C links to D..."
"We form: A→B→C→D = Chain of 4!"
"But if B links back to me: A→B→A = Loop of 2!"
"Loops are SHORT! We die!"
```

### Avoiding Loops:
```
"Don't link to someone who might link back to you"
"Link FORWARD in the social chain"
"Try to predict the chain direction"
```

### The Betrayal:
```
"I thought everyone was linking to me..."
"But they all linked to someone else!"
"I'm isolated! NO ONE linked to me!"
"I linked out, but no one linked IN!"
```

## 🔢 Chain Mechanics

```
CHAIN FORMATION:

Players: A, B, C, D, E, F, G, H (8 players)

Links revealed:
A → B
B → C
C → D
D → E
E → F
F → A (loops back!)
G → C
H → H (can't link to self, invalid)

Chains formed:
• A→B→C→D→E→F→A = LOOP of 6 (counts as 6)
• G→C joins the chain! = Now 7
• H = Isolated (linked to invalid)

Result:
• Chain of 7 = SURVIVES
• H = ELIMINATED
```

### Special Cases:

```
LOOPS:
A→B→C→A = Loop of 3
Still counts as chain length 3
But can't grow longer!

BRANCHES:
A→C, B→C = Both link to C
C→D
Forms: A→C→D and B→C→D
Longest path = 3

HUB (everyone links to one):
A→Z, B→Z, C→Z, D→Z
Z→? 
If Z links to A: Z→A, and A→Z = Loop of 2
All connected to the hub, but short chains!

ISOLATION:
X links to Y
But NO ONE links to X
X is a "tail" - still part of chain if Y is in chain
But if X→Y and Y→X only, it's just a loop of 2
```
