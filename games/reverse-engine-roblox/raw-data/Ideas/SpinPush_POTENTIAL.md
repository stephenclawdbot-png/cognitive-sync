## 🧠 The Physics Mind Games

### Spin Calculation:
```
"Platform spinning clockwise..."
"If I roll NORTH, spin will curve me EAST..."
"Actual trajectory = NORTHEAST"
"I need to account for spin!"
```

### Collision Prediction:
```
"His ball is to my left..."
"If I roll left, we collide!"
"Collision = both bounce back"
"Maybe I WANT to collide? To push him off?"
"Or maybe collision sends ME off the edge!"
```

### Edge Awareness:
```
"I'm near the edge..."
"If I roll toward center, I'm safer"
"But everyone is rolling to center..."
"COLLISION CHAOS in the middle!"
"Maybe edge is actually safer?"
```

### Momentum Chains:
```
"If A hits B, B hits C, C hits D..."
"Chain reaction!"
"One collision can cause MULTIPLE eliminations!"
"Where's the safest spot?"
```

## 🎱 Ball Physics

```
ROLLING:
- Balls roll in chosen direction
- Platform spin adds rotational momentum
- Final trajectory = direction + spin effect

COLLISION:
- Two balls collide = both bounce back
- Angle of collision affects bounce direction
- Heavier ball (power-up?) bounces less

EDGE:
- Roll off platform = fall into void
- Eliminated!
- Ball pops or floats away

SPIN EFFECT:
┌────────────────────────────────────┐
│                                    │
│   YOU → (roll right)               │
│                ↘                   │
│   Platform spin (clockwise)        │
│                  ↓                 │
│   Actual path = diagonal!          │
│                                    │
└────────────────────────────────────┘
```

## 🔄 Spin Mechanics

```
SPIN SPEED:
- Round 1-3: Slow spin
- Round 4-6: Medium spin
- Round 7+: Fast spin

SPIN DIRECTION:
- Usually clockwise
- Sometimes reverses! (chaos mode)

SPIN EFFECT ON TRAJECTORY:
- Slow spin = minor curve
- Fast spin = major curve
- Must predict!

STANDING STILL:
- Even if you don't roll, spin moves you
- Can't just camp in one spot
- Forces movement/decisions
```
