# 🪞 COPYCAT

> **Formula:** A (Timer-Reveal)
> **Core Mechanic:** Match the majority or die
> **Theme:** Cute animals mimicking
> **Status:** ORIGINAL CONCEPT - High Potential

---

## 🎯 Why This Is ORIGINAL

No existing game does this:
- Not Simon Says (that's follow the leader)
- Not Among Us (that's finding impostor)
- This is PURE SOCIAL PREDICTION

**The question each round:** "What will MOST people do?"

## 🎮 Turn Structure

```
┌─────────────────────────────────────────────────────────────────┐
│                    COPYCAT - TURN FLOW                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   PHASE 1: ACTION SHOWN (2 sec)                                 │
│   → Random action appears: "JUMP!"                              │
│   → Everyone sees it                                            │
│   → Clock starts                                                │
│                                                                 │
│   PHASE 2: SECRET CHOICE (5 sec)                                │
│   → Pick: [COPY ✓] or [IGNORE ✗]                                │
│   → You DON'T see others' choices                               │
│   → "What will everyone else do?"                               │
│   → Watching others for hints (but they're hiding too!)         │
│                                                                 │
│   PHASE 3: LOCK                                                 │
│   → "Revealing in 3... 2... 1..."                               │
│   → No changing your choice                                     │
│   → Maximum tension                                             │
│                                                                 │
│   PHASE 4: REVEAL                                               │
│   → Everyone performs their action (or stands still)            │
│   → Instantly see who copied vs who ignored                     │
│   → Count: "7 COPIED, 3 IGNORED"                                │
│   → Majority highlighted SAFE                                   │
│   → Minority = ELIMINATED (poof! confetti death)                │
│                                                                 │
│   PHASE 5: NEXT ROUND                                           │
│   → Survivors remain                                            │
│   → New action appears                                          │
│   → Repeat until 1 winner                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 🧠 The Mind Games (Why This Is GENIUS)

### Round 1 Thinking:
```
"Jump is shown..."
"Most people will probably copy... right?"
"So I should copy to be safe..."
"But wait, if EVERYONE thinks that..."
"Maybe some will rebel and ignore?"
"Should I be a rebel? Or play it safe?"
```

### Round 5 Thinking (5 players left):
```
"It's been 50/50 split lately..."
"That guy always copies..."
"She ignored last 2 times..."
"If I copy and 2 others ignore, I'm in minority!"
"But if I ignore and everyone copies, I'm DEAD!"
"WHAT DO I DO?!"
```

### The Spiral:
```
"If everyone copies, I should copy" →
"But if everyone THINKS that, some will ignore" →
"So maybe I should ignore?" →
"But if everyone thinks THAT..." →
INFINITE MIND GAMES
```

## 📊 The Math (Why It Works)

```
10 PLAYERS:
- 6+ copy = copiers survive
- 5+ ignore = ignorers survive
- Exact 5-5 tie = BOTH sides safe? Or random death?

8 PLAYERS:
- 5+ either way wins

4 PLAYERS:
- 3+ either way wins
- Getting HARDER to predict

2 PLAYERS (FINAL):
- Same choice = BOTH SURVIVE, sudden death round
- Different choice = ONE DIES, WINNER!
```

**Tie-breaker options:**
1. Both survive, new round
2. Random elimination from tied side
3. Fastest to choose survives

## 🔥 Advanced Mode: RULE SWITCH

Once players understand the basic game, introduce chaos:

```
RULE VARIATIONS (shown before action):

"MAJORITY SURVIVES" ← Normal
"MINORITY SURVIVES" ← Reversed! Rebels win!
"COPIERS SURVIVE" ← Copy always safe
"IGNORERS SURVIVE" ← Ignore always safe
"50/50 = EVERYONE DIES" ← Force a side!
```

**Why this is genius:**
- Keeps game fresh after 100 rounds
- Adds another layer of mind games
- "What's the rule THIS round?"
