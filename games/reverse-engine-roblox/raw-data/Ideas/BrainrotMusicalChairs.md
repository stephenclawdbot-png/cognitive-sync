# Brainrot Musical Chairs 🇮🇹🪑

**Status:** SAVED - High viral potential
**Theme:** Italian Brainrot + Classic party game
**Style:** Real-time scramble with elimination

---

## 🎮 Core Concept

Classic musical chairs but with Italian Brainrot characters. Music plays, walk around chairs, music STOPS = grab a chair or die. Can push others off chairs. Meme music and sounds.

**The Twist:** Classic game everyone knows + trending theme + combat = chaos.

---

## 🔄 Core Loop

```
┌─────────────────────────────────────────────────────────────────┐
│                  BRAINROT MUSICAL CHAIRS                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   1. ROUND SETUP                                                │
│      → Chairs spawn in circle (players - 1)                     │
│      → 8 players = 7 chairs                                     │
│      → All players stand around chairs                          │
│      → Music starts playing (Italian meme music)                │
│                                                                 │
│   2. MUSIC PHASE (10-20 seconds, random)                        │
│      → Music plays, everyone MUST keep moving                   │

│      → Can bump others but no sitting yet                       │

│   3. MUSIC STOPS                                                │
│      → Sudden stop (dramatic sound effect)                      │

│      → One chair per player                                     │
│                                                                 │
│   4. CHAIR COMBAT (3 seconds)                                   │
│      → Can PUSH someone off their chair                         │

│                                                                 │
│   5. ELIMINATION                                                │
│      → Player without chair = ELIMINATED                        │
│      → "MAMMA MIA!" death animation                             │
│      → One chair removed                                        │
│      → Back to step 1                                           │
│                                                                 │
│   6. VICTORY                                                    │
│      → 2 players, 1 chair, final showdown                       │
│      → Winner = CHAMPION                                        │
│                                                                 │

```

## 🪑 Chair Mechanics

### Chair States
| State | Visual | Rules |
|-------|--------|-------|
| Available | Glowing outline | Anyone can sit |
| Claimed | Player sitting | Can be pushed off (3 sec) |
| Locked | Solid color | Cannot be stolen |
| Removed | Disappears | Gone for round |

### Sitting Rules
```
TO SIT:
- Must be near chair
- Press SIT button / auto-sit on contact
- First contact = claim

CHAIR PRIORITY:
- First to sit = temporary owner
- Can be pushed off for 3 seconds
- After lock = permanent for round
```

---

## 🤜 Combat Mechanics

### Push Attack
| Property | Value |
|----------|-------|
| Range | Short melee |
| Effect | Knocks player off chair |
| Cooldown | 1.5 seconds |
| Window | Only during 3-sec scramble |

### Combat Scenarios
```
YOU'RE SITTING, ENEMY APPROACHES:
→ Brace (can't be pushed for 1 sec)
→ Or jump off and push THEM
→ Mind games

YOU'RE STANDING, ENEMY SITTING:
→ Push them off!
→ Quick sit on their chair
→ Hope no one pushes YOU

TWO PEOPLE PUSHING SAME CHAIR:
→ Both bounce off
→ Race to recover
→ Third player might steal it
```

## 🎵 Music System

### Music Phases
```
MUSIC PLAYING:
- Italian meme songs (Bombardiro theme, etc.)
- Random duration: 10-20 seconds
- No pattern (can't predict)
- Must keep moving!

MUSIC STOPS:
- Sudden silence
- Record scratch sound
- 0.5 sec freeze (dramatic)
- Then CHAOS
```

### Movement During Music
```
MUST MOVE:
- Walking minimum
- Circle around chairs
- Standing still = warning flash
- 3 sec still = auto-elimination!

WHY:
- Prevents camping
- Creates flow
- More chaotic when music stops
```

## 🎮 Game Modes

### Classic (Above)
- 8 players
- Standard elimination
- Last sitting wins

### Team Chairs
- 2 teams of 4
- Fight for chairs
- Team with more seated wins round
- Team elimination

### Speed Chairs
- Music stops every 5 seconds
- Rapid fire rounds
- Chaotic and fast

### Mega Chairs
- 16 players
- Huge chair circle
- Longer matches

### No Push Mode
- Pure speed
- No combat
- First to sit wins
- For younger players
