# 🌋 Floor Is Lava

> **Formula:** ORIGINAL (Not Knockout! Clone)
> **Core Mechanic:** POSITION prediction, not combat
> **Theme:** Cute animals jumping on furniture / islands
> **Status:** HIGH Potential - 100% Original Concept

---

## 🎯 Why This Is NOT a Knockout! Clone

| Knockout! | Floor Is Lava |
|-----------|---------------|
| Attack others | Survive environment |
| Push direction | Jump to position |
| Combat-based | Prediction-based |
| You eliminate others | Floor eliminates you |
| Horizontal | Vertical (falling) |

**This is SURVIVAL, not COMBAT.**

---

## 🧬 Core Concept

```
Grid of platforms/tiles/furniture.
Each round, some tiles will SINK INTO LAVA.
Everyone picks which tile to JUMP TO (hidden, simultaneous).
"Jumping in 3... 2... 1..."
Everyone jumps at same time.
Sinking tiles revealed AFTER jump.
Standing on sinking tile = FALL INTO LAVA = eliminated.
Fewer safe tiles each round.
Last one standing wins.
```

```

│                       FLOOR IS LAVA                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   PHASE 1: TILES SHOWN                                          │
│   → Grid of tiles visible                                       │
│   → Previous round's sunk tiles = holes                         │
│   → Players see current positions                               │
│                                                                 │
│   PHASE 2: PICK DESTINATION (hidden, 8 sec)                     │
│   → Everyone picks which tile to JUMP TO                        │

│   → You DON'T see others' choices                               │
│   → "Will this tile sink? Should I move?"                       │
│                                                                 │
│   PHASE 3: LOCK                                                 │
│   → "Jumping in 3... 2... 1..."                                 │
│   → Suspense builds                                             │
│   → Rumbling sounds...                                          │
│                                                                 │
│   PHASE 4: JUMP!                                                │
│   → Everyone jumps simultaneously                               │
│   → Mid-air moment                                              │
│   → Collision possible if same tile!                            │
│                                                                 │
│   PHASE 5: SINK REVEAL                                          │
│   → Random tiles start SINKING                                  │
│   → Lava bubbles up                                             │
│   → Standing on sinking tile = FALL IN                          │
│   → Dramatic slow-mo fall                                       │
│                                                                 │
│   PHASE 6: SETTLE                                               │
│   → Survivors on safe tiles                                     │
│   → Sunk tiles now holes                                        │
│   → Fewer tiles for next round                                  │
│   → Repeat until winner                                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 🔥 The Sinking Mechanic

```
SINK STAGES:

Round 1: All tiles safe
┌────┐ ┌────┐ ┌────┐
│SAFE│ │SAFE│ │SAFE│
└────┘ └────┘ └────┘

Round 2: Some tiles sink
┌────┐ ┌────┐ ┌────┐
│SAFE│ │🔥🔥│ │SAFE│
└────┘ │SUNK│ └────┘
       └────┘

Round 5: Barely any safe!
┌────┐
│SAFE│  🔥🔥🔥🔥🔥🔥
└────┘  🔥🔥🔥🔥🔥🔥

THE DRAMA:
- Tile starts SHAKING
- Cracks appear
- Sinks slowly into lava
- Player standing on it: 😱
- Falls in slow motion
- SPLASH into lava (comedic, not violent)
```

---

## 💥 Collision Mechanic

```
WHAT IF TWO PLAYERS JUMP TO SAME TILE?

Option A: Both safe (crowded)
- Tile holds both
- But TWICE as likely to sink next round!

Option B: Bump off (one falls)
- First to land = safe
- Second = bounced into lava
- Creates "racing" element

Option C: Both bounce
- Tile too crowded
- Both bounce to adjacent tiles
- Neither controls where they land

RECOMMENDED: Option A (simpler, less frustrating)
But crowded tiles are HIGH RISK next round!
```

## 🧠 Strategic Depth

```
READING THE ROOM:
"That platform has 3 people... risky!"
"Edge platforms might sink first?"
"Center platform is crowded but maybe safer?"

PREDICTION:
"He's been on that couch 3 rounds... he'll move"
"She always goes left"
"Everyone will avoid the crowded spot"

RISK MANAGEMENT:
"Stay on safe-looking platform?"
"Or jump to less crowded one?"
"Crowded = high risk next round"

SOCIAL DYNAMICS:
"If I jump there, I'll crowd him out"
"Should I follow the group or go alone?"
```
