# 👑 CROWN CHASE

> **Formula:** C (Asymmetric Hunt)
> **Core Mechanic:** Grab the crown, survive as king
> **Theme:** Cute animals fighting for royalty
> **Status:** ORIGINAL CONCEPT - High Potential

---

## 🎯 Why This Is ORIGINAL

Combines proven elements in a NEW way:
- NOT just tag (king changes dynamically)
- NOT just king of the hill (there's active hunting)
- NOT just race (being king is DANGEROUS)

**The core tension:** Being king = power AND target

---

```
┌─────────────────────────────────────────────────────────────────┐
│                       CROWN CHASE                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   CROWN spawns in CENTER of arena                               │

```

## 🧠 Strategic Depth

### As KING:
```
"I have 15 seconds to survive..."
"Everyone can see me (glowing!)..."
"Should I run? Hide? Fight back?"
"Use the environment for cover!"
"Kite them in circles!"
"Make them bump into each other!"
```

### As HUNTER:
```
"I need to kill the king..."
"But if I kill him, I become king..."
"And then I'M the target!"
"Should I let someone else kill him?"
"But if he survives, a hunter dies!"
"DO I WANT TO BE KING OR NOT?"
```

### The Beautiful Paradox:
```
BEING KING = 
  ✓ You're alive (for now)
  ✓ You control your fate
  ✗ EVERYONE is trying to kill you
  ✗ You're glowing and visible

NOT BEING KING = 
  ✓ You can hide in the crowd
  ✓ Less immediate danger
  ✗ If king survives, random hunter dies
  ✗ No control over your fate
```

**The question:** Is it better to be king (targeted but in control) or hunter (safer but random death risk)?

## ⚔️ Combat System

### Simple Attack:
```
ONE attack button
Get close + press attack = hit
Hit the king = crown transfers
Hit a hunter = nothing happens (no friendly fire?)
OR: Hunters can hit each other for chaos!
```

### King Powers (Optional):
```
King gets ONE advantage to make it fair:
- Slightly faster movement? (10% speed boost)
- One shield/dodge? (absorb 1 hit)
- Brief invisibility burst? (1 sec vanish)
- Push ability? (knock hunters back)

OR: King has NO advantage (pure skill)
```

### Movement:
```
All players can:
- Run (standard speed)
- Dash (quick burst, cooldown)
- Jump (hop over obstacles)

Simple, no complex combos
```
