# Buildbreak 🧱💥

**Status:** SAVED - High potential
**Theme:** Build AND destroy (Minecraft energy)
**Style:** Phase-based strategy + combat

---

## 🎮 Core Concept

Two phases alternate: BUILD your tower (safe zone), then BREAK others' towers. Your tower is your life — if it falls, you're eliminated. Strategic building meets chaotic destruction.

**The Twist:** What you BUILD determines how you SURVIVE. Architecture = strategy.

---

## 🔄 Core Loop

```
┌─────────────────────────────────────────────────────────────────┐
│                       BUILDBREAK LOOP                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   1. BUILD PHASE (30 seconds)                                   │
│      → Each player has a SPAWN PLATFORM                         │
│      → Blocks spawn/regenerate in your zone                     │
│      → Stack blocks to build your TOWER                         │
│      → Tower = your SAFE ZONE during break phase                │
│      → Can't leave your build zone                              │
│      → Can't attack others yet                                  │
│                                                                 │
│   2. BREAK PHASE (45 seconds)                                   │
│      → "BREAK TIME!" - barriers drop                            │
│      → Run to OTHER players' towers                             │
│      → DESTROY their structures!                                │
│      → Punch blocks, throw bombs, use tools                     │
│      → If tower collapses = owner falls = ELIMINATED            │
│      → Defend YOUR tower from attackers!                        │
│                                                                 │
│   3. SURVIVAL CHECK                                             │
│      → Phase ends                                               │
│      → Anyone who fell during break = OUT                       │
│      → Survivors return to their platforms                      │
│      → Damaged towers stay damaged!                             │
│                                                                 │
│   4. REPEAT                                                     │
│      → New BUILD PHASE (repair + expand)                        │
│      → New BREAK PHASE                                          │
│      → Continue until 1 player remains                          │
│                                                                 │
│   5. VICTORY                                                    │
│      → Last player with standing tower WINS                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 🧱 Building Mechanics

### Block Types
| Block | Strength | Speed to Place | Special |
|-------|----------|----------------|---------|
| Wood | 1 HP | Fast | Burns (fire hazard) |
| Stone | 3 HP | Medium | Heavy, stable |
| Metal | 5 HP | Slow | Strongest |
| Glass | 1 HP | Fast | See-through |
| Bounce | 2 HP | Medium | Bounces attackers off |

### Building Rules
```
PLACEMENT:
- Blocks must connect to something
- Can build up, out, around
- Limited blocks per phase (30 blocks?)
- Unused blocks = wasted

HEIGHT:
- Taller = safer from ground attacks
- BUT taller = less stable
- Strong winds can topple tall towers

WIDTH:
- Wider base = more stable
- BUT more surface to defend
- Takes longer to build
```

### Tower Strategies
```
THE FORTRESS:
- Wide, low, thick walls
- Hard to break through
- Easy to defend
- Weakness: can climb over

THE SKYSCRAPER:
- Tall and thin
- Hard to reach top
- Weakness: unstable, one break = collapse

THE BUNKER:
- Enclosed box
- Safe from all sides
- Weakness: trapped inside, hard to escape

THE MAZE:
- Confusing layout
- Attackers get lost
- Weakness: takes time to build

THE HYBRID:
- Tall with wide base
- Best of both worlds
- Requires skill
```

## 💥 Breaking Mechanics

### Attack Options
| Attack | Damage | Range | Cooldown |
|--------|--------|-------|----------|
| Punch | 1 dmg | Melee | None |
| Thrown Rock | 2 dmg | Medium | 1 sec |
| Bomb | 3 dmg (AoE) | Throw | 5 sec |
| Pickaxe | 4 dmg | Melee | 2 sec |
| TNT | 10 dmg (huge) | Place | 10 sec |

### Attack Strategies
```
BOTTOM BREAKER:
- Attack foundation
- Tower collapses entirely
- High risk: debris falls on you

TOP SNIPER:
- Climb up, attack top
- Owner falls even if tower stands
- Need to reach top first

TEAMWORK:
- Multiple attackers
- Overwhelm one player
- Risk: your tower undefended

DEFENDER:
- Stay home, protect tower
- Attack anyone who comes
- Don't need to attack others
- Win by survival
```

---

## 🏠 Defense Mechanics

### Defending Your Tower
```
ACTIVE DEFENSE:
- Punch attackers off your tower
- Throw them down
- Block entrances with your body

PASSIVE DEFENSE:
- Build thick walls
- Multiple layers
- Mazes and dead ends
- Bounce pads to knock people off
```

### Repair During Build Phase
```
- Damaged blocks can be replaced
- New blocks spawn each build phase
- Prioritize: foundation > walls > height
- Can redesign between phases
```

## 🎮 Game Modes

### Classic (Above)
- Build 30 sec, Break 45 sec
- Last standing wins

### Speed Build
- Build 15 sec, Break 30 sec
- Faster rounds, less elaborate towers

### Team Build
- 2v2, 3v3, 4v4
- Shared tower per team
- Multiple builders + defenders

### Infinite Build
- One long build phase (2 min)
- One massive break phase
- Epic scale battles

### King Tower
- One MEGA tower in center
- Everyone builds toward it
- Reach the top = win
- Can knock others down
