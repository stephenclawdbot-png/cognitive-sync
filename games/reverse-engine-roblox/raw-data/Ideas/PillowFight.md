# 🛏️ Pillow Fight

> **Formula:** A (Timer-Reveal, like Knockout!)
> **Physics Type:** SWINGING (knockback with feathers!)
> **Theme:** Cute animals having a sleepover pillow fight
> **Status:** VERY HIGH Potential - Ultra family-friendly, universal

---

## 🎯 Core Concept

```
Cute animals at a sleepover.
Everyone has a PILLOW.
Standing on a giant bed.
Pick SWING DIRECTION (hidden).
Pick SWING POWER (hidden).
Hit = knockback + FEATHERS EXPLODE!
Edge of bed = fall off = eliminated.
Bed bounces a little (soft physics).
```

## 🎮 Turn Structure

```
┌─────────────────────────────────────────────────────────────────┐
│                      PILLOW FIGHT                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   PHASE 1: SWING DIRECTION (hidden, 10 sec)                     │
│   → Everyone picks which way to swing pillow                    │
│   → 8 directions (or toward nearest player?)                    │
│   → You DON'T see others' choices                               │
│                                                                 │
│   PHASE 2: SWING POWER (hidden)                                 │
│   → Pick how hard to swing (1-10)                               │
│   → More power = more knockback                                 │
│   → More power = more FEATHERS!                                 │
│                                                                 │
│   PHASE 3: LOCK                                                 │
│   → "Swinging in 3... 2... 1..."                                │
│   → Everyone winds up their pillow                              │
│   → Suspense builds                                             │
│                                                                 │
│   PHASE 4: THWACK!                                              │
│   → ALL pillows swing at once                                   │
│   → Hits connect                                                │
│   → FEATHERS EXPLODE from impacts!                              │
│   → Knockback toward bed edges                                  │
│   → Fall off bed = eliminated                                   │
│                                                                 │
│   PHASE 5: BEDTIME (Shrink)                                     │
│   → Bed gets smaller (pillows pushed aside)                     │
│   → Less room                                                   │
│   → Repeat until winner                                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
